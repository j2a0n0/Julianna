# Security policy

Security reports for Julianna must be submitted privately through the Security tab of the public source repository configured by `JULIANNA_SOURCE_URL`. Do not open a public issue for an unpatched vulnerability.

Include the affected Julianna version and commit, deployment details, reproduction steps, impact, and any suggested remediation. Maintainers should acknowledge a complete report within two business days and coordinate disclosure after a fix is available.

Production operators should use HTTPS, keep PHP and dependencies current, protect the application encryption key, require MFA, restrict database access, and maintain tested backups.
